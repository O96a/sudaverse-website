Comprehensive Technical Resources for the Sudaverse Ecosystem

Welcome to the Sudaverse Ecosystem

Sudaverse is a comprehensive ecosystem of tools, datasets, and applications dedicated to building Sudanese-Arabic-centric AI solutions. Our mission is to preserve and advance Sudanese linguistic heritage in the digital age by creating robust, accessible, and culturally-aware AI technologies.

The Sudaverse ecosystem encompasses multiple interconnected components designed to support the entire AI development lifecycle for Sudanese Arabic:

  • Data Pipelines: End-to-end tools for collecting, cleaning, and curating high-quality Sudanese Arabic text
  • LLM Tools: Large language model development utilities, from corpus refinement to fine-tuning frameworks
  • Benchmarks: Comprehensive evaluation suites for measuring tokenizer and model performance on Sudanese dialects
  • Applications: Production-ready tools like SudaTutor that leverage our AI infrastructure
  • Datasets: Curated collections of Sudanese Arabic text across multiple domains and dialects
  • Models: Pre-trained and fine-tuned language models specifically designed for Sudanese Arabic

All Sudaverse projects are developed with a commitment to open collaboration, cultural sensitivity, and technical excellence. We welcome contributions from researchers, developers, and community members who share our vision of AI that serves Sudanese people.

SuData - Data Normalization Pipeline ACTIVE

Repository: github.com/O96a/SuData

Overview

SuData is an end-to-end data normalization and curation pipeline specifically designed for Sudanese Arabic text processing. It provides a comprehensive suite of tools for transforming raw, unstructured Arabic text into clean, standardized datasets that are ready for machine learning applications.

The pipeline handles the unique challenges of Sudanese Arabic, including dialect variations, code-switching, informal writing styles, and cultural-specific expressions that standard Arabic NLP tools often miss.

Key Features
🧹 Robust Cleaning

Removes noise, emojis, HTML tags, special characters, and unwanted formatting while preserving meaningful Arabic diacritics and punctuation.

📝 Dialect-Aware Normalization

Intelligent spelling normalization that understands Sudanese dialect variations and normalizes them consistently without losing dialectal authenticity.

🔒 PII Removal

Automatic detection and removal of personally identifiable information (names, phone numbers, emails) to ensure privacy compliance.

♻️ Deduplication

Advanced deduplication algorithms that identify and remove duplicate or near-duplicate text entries across large datasets.

Installation & Usage
# Install SuData
pip install sudata

# Basic usage
from sudata import Pipeline

# Initialize pipeline
pipeline = Pipeline(
  clean_html=True,
  normalize_spelling=True,
  remove_pii=True,
  deduplicate=True
)

# Process text
cleaned_text = pipeline.process("Your raw Arabic text here")

# Batch processing
pipeline.process_file("input.txt", "output.json")
Export Formats
  • JSON: Structured data with metadata
  • JSONL: Line-delimited JSON for streaming
  • CSV: Tabular format for analysis
  • Parquet: Columnar format for big data
Use Cases
  • Preparing training data for language models
  • Cleaning social media datasets
  • Normalizing historical text archives
  • Building domain-specific corpora

LLMCorpusKit - Corpus Refinery ACTIVE

Repository: github.com/O96a/LLMCorpusKit

Overview

LLMCorpusKit (Corpus Refinery) is a sophisticated large-scale Arabic corpus cleaning and polishing toolkit that leverages AI-powered semantic repairs. Unlike basic text cleaning tools, LLMCorpusKit performs intelligent repairs and improvements on text corpora, making them suitable for high-quality LLM training.

The toolkit integrates with state-of-the-art language models to understand context and perform semantic repairs that go beyond rule-based cleaning, ensuring that the refined corpus maintains linguistic coherence and cultural authenticity.

Key Features
🔬 Deep-Cleaning Workflows

Multi-stage cleaning pipelines that progressively refine text quality, from surface-level normalization to deep semantic analysis.

🛠️ Sentence Repair

AI-powered sentence structure correction that fixes grammatical errors, incomplete sentences, and fragmented text while preserving meaning.

🔌 API Integration

Seamless integration with Gemini, GPT, and other LLM APIs for intelligent text enhancement and quality assessment.

⚡ Bulk & Streaming

Efficient bulk processing for large corpora and streaming capabilities for real-time data pipelines.

Installation & Usage
# Install LLMCorpusKit
pip install llmcorpuskit

# Import and configure
from llmcorpuskit import CorpusRefinery

# Initialize with API credentials
refinery = CorpusRefinery(
  api_provider="gemini",
  api_key="YOUR_API_KEY",
  model="gemini-pro"
)

# Process corpus
refined_corpus = refinery.refine_corpus(
  input_file="raw_corpus.txt",
  output_file="refined_corpus.txt",
  repair_sentences=True,
  check_coherence=True
)
Refinery Stages
  1. Pre-processing: Basic normalization and filtering
  2. Semantic Analysis: Context understanding and validation
  3. Repair & Enhancement: AI-powered text improvement
  4. Quality Assurance: Automated quality checks
  5. Post-processing: Final formatting and export
Advanced Features
  • Context-Aware Repair: Maintains discourse coherence across paragraphs
  • Dialect Preservation: Repairs text while preserving dialectal features
  • Quality Scoring: Assigns quality metrics to each text segment
  • Parallel Processing: Multi-threaded processing for large datasets
  • Custom Rules: Extensible rule engine for domain-specific refinement

Sudanese Dialect Benchmark PLANNED

Repository: Coming soon

Overview

The Sudanese Dialect Benchmark is a comprehensive evaluation suite designed to measure how well tokenizers and language models handle Sudanese Arabic dialects, slang, and regional variations. This benchmark provides standardized metrics and evaluation protocols for assessing model performance on Sudanese-specific linguistic phenomena.

Unlike generic Arabic benchmarks that focus on Modern Standard Arabic (MSA), this suite specifically targets the unique characteristics of Sudanese dialects, including code-mixing, colloquialisms, and cultural expressions.

Key Features
🎯 Tokenization Metrics

Comprehensive evaluation of tokenizer performance including fertility, coverage, and efficiency on Sudanese text.

✅ Coverage Tests

Systematic testing of model vocabulary coverage for Sudanese slang, colloquial expressions, and regional variants.

⚖️ Multi-Tokenizer Comparison

Side-by-side comparison framework for evaluating different tokenizers (BPE, WordPiece, SentencePiece) on Sudanese data.

📊 Dialect Fitness Scoring

Novel scoring system that quantifies how well a model or tokenizer is suited for specific Sudanese dialects.

Benchmark Components
  1. Tokenization Benchmark: Evaluates tokenizer efficiency and quality
  2. Language Understanding: Tests comprehension of dialectal nuances
  3. Generation Quality: Assesses fluency and authenticity of generated text
  4. Cultural Awareness: Measures understanding of cultural context
  5. Code-Switching: Tests handling of Arabic-English mixing
Evaluation Metrics
  • Tokenization Fertility: Average tokens per word
  • Vocabulary Coverage: Percentage of OOV (out-of-vocabulary) terms
  • Dialect Accuracy: Correct identification of dialectal features
  • Semantic Preservation: Meaning retention after tokenization
  • Cultural Appropriateness: Alignment with cultural norms and expressions
Planned Test Suites
  • Dialectal Variation: 1000+ examples across regional dialects
  • Slang & Colloquialisms: 500+ common Sudanese expressions
  • Code-Switching: 300+ mixed language examples
  • Cultural References: 200+ culturally-specific contexts
  • Domain-Specific: Test sets for medical, legal, educational domains

Status: Under active development. Expected release: Q3 2026

System Architecture

The Sudaverse ecosystem components work together in a cohesive pipeline, from raw data collection through model deployment. Understanding this architecture helps developers integrate these tools effectively.

Pipeline Overview
  1. Data Collection: Gather raw Sudanese Arabic text from various sources
  2. SuData Processing: Initial cleaning and normalization
  3. LLMCorpusKit Refinement: Deep cleaning and semantic repair
  4. Synthetic Augmentation: Generate additional training examples
  5. Data Hub Storage: Catalog and distribute curated datasets
  6. Model Training: Train language models on processed data
  7. Benchmark Evaluation: Assess model performance
  8. Application Deployment: Deploy in production (e.g., SudaTutor)
Integration Points

Each component exposes APIs and data formats that allow seamless integration:

  • SuData → LLMCorpusKit: Cleaned text feeds into refinement pipeline
  • LLMCorpusKit → Synthetic Generator: High-quality corpus seeds synthetic generation
  • All Components → Data Hub: Output datasets registered in central catalog
  • Data Hub → Model Training: Curated datasets downloaded for training
  • Trained Models → Benchmark: Models evaluated against standard metrics

Development Setup

Get started contributing to Sudaverse projects with our standardized development environment.

Prerequisites
  • Python 3.8 or higher
  • Git for version control
  • Virtual environment tool (venv, conda, or poetry)
Quick Start
# Clone repository
git clone https://github.com/O96a/[project-name].git
cd [project-name]

# Create virtual environment
python -m venv venv
source venv/bin/activate # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
pip install -r requirements-dev.txt

# Run tests
pytest tests/

# Start developing!
